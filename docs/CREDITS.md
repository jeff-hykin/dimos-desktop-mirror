# Credits

## Robot-type icons (ui/src/assets/robot_icons/)

The Launcher's robot icons are modified versions of these works (vectorized, line weight normalized, restyled; the
wheeled robot puts the humanoid's upper body on an original column and chassis):

- humanoid.svg, wheeled.svg (upper body): "Humanoid robot" by Izwar Muis, from the Noun Project,
  https://thenounproject.com/icon/humanoid-robot-8041298/ — CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/)
- dog.svg: "robot dog" by Izwar Muis, from the Noun Project, https://thenounproject.com/icon/robot-dog-8041305/ — CC BY
  3.0
- arm.svg: "Robotics" by rukanicon, from the Noun Project, https://thenounproject.com/icon/robotics-5920654/ — CC BY 3.0
- drone.svg: Tabler Icons "drone", https://tabler.io/icons — MIT License
- robot.svg, custom.svg: dimOS originals

Each has a `*_research.svg` twin for the Research theme. Settings → Services shows the same attribution.
